# af-magic-simple

A minimal [oh-my-zsh](https://ohmyz.sh) theme based on `af-magic`: just the current directory and a `»` prompt, with a blank line between commands. No git info, no right-side user@host.

```sh
curl -fsSL https://raw.githubusercontent.com/drewmutt/af-magic-simple/main/install.sh | bash
```

Requires oh-my-zsh. The installer puts the theme in your custom themes folder and sets `ZSH_THEME="af-magic-simple"` in `~/.zshrc` (saving a backup to `~/.zshrc.bak`). Then open a new terminal or run `exec zsh`.
